# QA Mart Project Instruction Reference

This file is bundled as reference material. Plugins do not install workspace-wide Copilot instructions as first-class components.

For QA Mart Playwright work, preserve the project conventions: use accessible locators and shared fixtures/data, prefer web-first assertions, keep assertions in specs, link tests to stories, and do not edit `app/` to make tests pass. See the repository's `.github/copilot-instructions.md` for the active workspace guidance.

For manual testcase work, use the rules in `manual-test-case-rules.md` and the workflow skill `manual-test-case-creation`.
